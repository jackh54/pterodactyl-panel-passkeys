Features

Passkeys, built into your panel

A Pterodactyl Panel 2.0 extension. Install the .pteroext and every user can add a passkey.

Sign in with a passkey

A button under the normal login form. Face ID, Touch ID, Windows Hello, your phone or a security key.

Counts as two-step

User verification is always required, so a passkey sign-in is two-step on its own. No TOTP code to type.

A Passkeys card in Account

Add one with your current password, name it, and see a synced badge and when each was last used.

Works with password managers

iCloud Keychain, Google Password Manager, 1Password and Bitwarden passkeys all work.

Up to 10 per account

The limit is admin configurable. Removing a passkey asks for the account password too.

A one-time nudge

A dashboard notice invites users to add a passkey. Each account can dismiss it for good.
